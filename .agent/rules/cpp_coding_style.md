# コーディングスタイル

FireballプロジェクトにおけるC++コードの記述、フォーマット、およびベストプラクティスに関する**最新かつ完全な情報**は、以下の統合コーディング規約ドキュメントを参照すること。

## 統合コーディング規約の主な内容

*   **一般原則**: 標準C/C++準拠、メモリ効率最優先、設計駆動開発、契約優先など。
*   **ファイル構造とインクルードガード**: `.hxx`, `.cxx` ファイルの規則、`#pragma once` の使用。
*   **命名規則**: `snake_case`、`UPPER_SNAKE_CASE`、メンバー変数接尾辞、型接尾辞 `_t` の制限など。
*   **型語彙とエイリアス**: `fireball_vocabulary/SKILL.md` に基づく推奨C++型エイリアスの利用。
*   **フォーマット**: インデント、波括弧スタイル (K&R)、行の長さ、ポインタ・参照の配置、アクセス修飾子のインデント。
*   **コメントとドキュメンテーション**: ソースコードのコメントは英語、契約の記述方法、`TODO` の使用。
*   **モダンC++とベストプラクティス**: C++20以降の機能、効率的な引数渡し、静的確定、所有権管理 (RAII)。
*   **禁止されるコンテナとテクニック**: `docs/orders/patterns/stdlib.md` への参照。
*   **インターフェース定義のワークフロー**: `development_cycle.md` からの抜粋。
