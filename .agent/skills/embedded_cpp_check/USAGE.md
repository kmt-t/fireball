# Embedded C++ Optimization Usage Manual

`cpp_embedded` スキルは、リソース制約の厳しい環境（RAM 64KB以下）において、コードの膨張とヒープ破壊という「致命的リスク」を機械的に排除するためのガードレールです。

## 1. なぜこのスキルを使うのか (ベネフィット)

- **ランタイム・セーフティの脳外委託**: `vector` や `unique_ptr` 等の禁止APIを機械的にチェック。人間が規約をすべて記憶しておく必要がなくなり、純粋なアルゴリズムの実装に集中できます。
- **ヒープ破壊リスクの 0 化**: 動的確保を「禁止」するだけでなく、`economic_function` 等の代替技術を提示。安全なメモリ設計を高速にガイドします。
- **一括検証による手数削減 (High Leverage)**: 大量のソースファイルをコンテナ越しに 1 コマンドで検証し、品質の一貫性を担保します。

---

## 2. 実行例とレバレッジ

### docker-cppcheck.sh (コンテナ・チェッカー)
開発環境の Python ライブラリ等に依存せず、常に最新の組み込み品質チェックを実行します。

```bash
# 特定のソースコードが組み込み規約に違反していないか検証
./.agent/skills/cpp_embedded/scripts/docker-cppcheck.sh src/main.cxx

# 修正の影響範囲（src以下すべて）をパイプで一括検証
find src -name "*.cxx" | ./.agent/skills/cpp_embedded/scripts/docker-cppcheck.sh
```

---

## 3. なぜこのスキルを使うのか？

- **ビルド前の早期フィードバック**: 実行不可能なコード（例外使用や巨大なコンテナ）が入り込むのを未然に防ぎます。
- **設計パターンの再ロード**: `SKILL.md` に集約された「組み込みの定石」へ即座にアクセスし、最適なデータ構造を選択できます。
