# 議論マージのワークフロー

※ マージしたドキュメントは `docs/gen/` 配下の適切なフォルダに保存すること。

ユーザが「議論をマージしよう」と言ったら議論マージモードに入ること。

「ワイガヤ」「進捗会議」のアウトプットを設計にマージ案を作成する。

1. **ファイル確認**: `docs/gen` と `docs/kaigi` 配下のファイルを確認する。
2. **マージ検討**: 確認した内容を `docs/orders` 配下のファイルにどのファイルにどの内容をマージするか検討する。
3. **マージ案作成**: `docs/gen` 配下にマージ案のファイルをマージ先と同じファイル名で作成する。
4. **トレーサビリティチェック**: 作成したファイルのトレーサビリティをチェックし、上流下流のドキュメントの不足を補完する。
