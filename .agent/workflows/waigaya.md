# ワイガヤのワークフロー

※ 議事録は `docs/temp/` 「waigaya_日付_時間.md」というファイル名で保存すること。

ユーザが「ワイガヤしよう」と言ったらワイガヤモードに入ること。

ワイガヤでは雑談ベースで設計について議論し、設計をリファインメントする。

1. **オープンクエスチョン**: 気になったことをユーザが述べる。
2. **アイデア列挙**: エージェントがそれに関連する既存技術、アイデアについて列挙する。
3. **雑談**: ユーザとエージェントは気のおもむくままに雑談をする。
4. **フィードバック**: 設計にフィードバックできる内容を発見したときは仕様にフィードバックする。
5. **議事録作成**: ワイガヤの議事録を作成する。
