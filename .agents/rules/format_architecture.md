scope: LOCAL
instructions: |
  アーキテクチャ設計ドキュメントの作成・編集時は、該当領域の形式定義に従い、
  完了前に以下のチェックリストを全項目確認すること。
  1. システムレイヤー構成が定義され、各レイヤーの責務が明確か
  2. コンポーネント間の依存方向がアーキテクチャ原則（例：クリーンアーキテクチャ）に従っているか
  3. 主要な動的振る舞い（シーケンス）が定義されているか
  4. 重要な設計上のトレードオフ（性能 vs メモリ等）が ADR として記録されているか
  5. 共通ポリシー（エラー、メモリ、ログ）が定義されているか
  6. 直交表を用いた主要な振る舞いの組み合わせ（動的モデル）の網羅性が検討されているか
  7. Mermaid図が含まれる場合、文法が正しく、Mermaidで正しくレンダリングされることを確認すること
      - BDD（graph TD）: ブロック、プロパティ、ポート、コネクタが正しく接続しているか
      - stateDiagram-v2: 複合状態の構造と遷移が正しいか
      - sequenceDiagram: システムレベルの相互作用フローが明確か
