# デバッガ仕様バックログ

## 概要
本節はデバッガ仕様の未確定事項を整理する。

## 未確定事項
1. **汎用エラーコード体系の策定**
   - RSPの`ENN`に対応する全体仕様のエラーコード体系が未定義。
   - 暫定コードを採用しているため、汎用体系策定後に統合が必要。

2. **マルチゲスト対応**
   - 1ゲスト=1スレッド固定としているが、将来的に複数ゲストのRSPマッピングを定義する必要がある。

3. **レジスタモデルの確定**
   - `g/G/p/P` が参照する仮想レジスタ集合の定義が暫定。
   - DWARFやWASMのデバッグ情報との連携方針を要検討。

4. **RSPパケットサイズ上限の決定**
   - `DebugConfig.max_packet_size` の具体値が未定義。
   - ターゲットごとのUARTバッファ制約との整合が必要。

5. **停止理由とシグナル対応の整合**
   - `TrapCause` と `S/T` 応答のシグナル番号の対応付けが未定義。
   - 汎用エラー/シグナル体系策定時に統合する。
