# 実装可能性評価に基づくバックログ

## 1. 仕様の不整合修正

- [ ] **ヒープサイズ定義の統一**: `overview.md` と `config.md` の数値範囲を RAM 64KB 制約に合わせて統一する。
- [ ] **コルーチン用語の再定義**: `CORO_STACK_SIZE` を `CORO_FRAME_SIZE` に改称し、スタックレスコルーチンにおける意味を明確化する。

## 2. 技術的課題の棚上げ（要詳細設計）

- [ ] **RSPサブセットの選定**: 15 KLOC制限を守るため、VSCodeデバッグに必要な最小限のRSPコマンドセットを特定し、仕様化する。
- [ ] **WASIサポート範囲の特定**: ゲストアプリケーションが必要とする最小限のWASI APIをリストアップし、HALとのマッピングを定義する。
- [ ] **JITキャッシュ運用シミュレーション**: RAM 24KBのゲスト環境において、JITキャッシュのフラッシュ頻度とパフォーマンスのトレードオフを検証する。

## 3. 表記揺れの修正

- [ ] **ドキュメント全域の用語統一**: `traceability_check.md` で指摘された用語（`co_sched`, `co_csp` 等）への統一を行う。
