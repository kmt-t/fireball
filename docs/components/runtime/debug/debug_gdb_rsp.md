# サポートGDB RSPコマンドセット

## 1. 概要
<!-- traceability: {RSPMinimalSet} -->
VSCodeのC/C++拡張機能が必要とするGDB Remote Serial Protocol (RSP) コマンドの最小セットを定義する。 `{RSPMinimalSet}`

## 2. コマンドリスト

### 2.1 セッション管理
| コマンド | 形式 | 説明 |
| :--- | :--- | :--- |
| `?` | `?` | 停止理由を問い合わせ |
| `c` | `c[addr]` | 実行を継続 |
| `C` | `C sig[;addr]` | シグナル付きで継続 |
| `s` | `s[addr]` | ステップ実行 |
| `S` | `S sig[;addr]` | シグナル付きでステップ実行 |
| `k` | `k` | ターゲットを終了 |

### 2.2 メモリアクセス
| コマンド | 形式 | 説明 |
| :--- | :--- | :--- |
| `m` | `m addr,length` | メモリを読み出す |
| `M` | `M addr,length:XX...` | メモリに書き込む |
| `X` | `X addr,length:XX...` | バイナリデータでメモリに書き込む |

### 2.3 レジスタアクセス
| コマンド | 形式 | 説明 |
| :--- | :--- | :--- |
| `g` | `g` | すべてのレジスタを読み出す |
| `G` | `G XX...` | すべてのレジスタに書き込む |
| `p` | `p n` | レジスタnを読み出す |
| `P` | `P n=XX...` | レジスタnに書き込む |

### 2.4 ブレークポイント
| コマンド | 形式 | 説明 |
| :--- | :--- | :--- |
| `z` | `z type,addr,kind` | ブレークポイント/ウォッチポイントを削除 |
| `Z` | `Z type,addr,kind` | ブレークポイント/ウォッチポイントを設定 |

**サポートタイプ**:
- `0`: ソフトウェアブレークポイント (必須)
- `1-4`: ハードウェア/ウォッチポイント (オプション)

### 2.5 スレッド・情報取得
| コマンド | 形式 | 説明 |
| :--- | :--- | :--- |
| `H` | `H op thread-id` | スレッドを選択 |
| `T` | `T thread-id` | スレッド情報を取得 |
| `qSupported` | `qSupported[:features]` | サポート機能を問い合わせ |
| `qfThreadInfo` | `qfThreadInfo` | スレッド一覧を問い合わせ |
| `qsThreadInfo` | `qsThreadInfo` | スレッド一覧の続き |

## 3. 応答形式
| 応答 | 説明 |
| :--- | :--- |
| `OK` | コマンド成功 |
| `ENN` | エラー（NNはエラーコード） |
| `S AA` | シグナルAAで停止 |
| `T AA name:r value;...` | 停止情報（レジスタ値付き） |
| `W AA` | シグナルAAで終了 |
