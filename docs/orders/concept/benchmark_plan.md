# vSoC ベンチマーク計画書

## 目的
Fireball vSoCのインタープリタ性能およびメモリ効率が、目標とする比較対象（WAMR）に対して優位性があることを早期に証明する。 `{vSoC_Benchmark_Goal}`

## 比較対象
- **WAMR (WebAssembly Micro Runtime)**
  - モード: インタープリタ（Classic または Fast）
  - 設定: AOT/JIT無効、浮動小数点演算無効（Fireballの条件に合わせる）

## 評価指標 (Metrics)
1. **実行性能 (Performance)**: 特定の計算タスク（CoreMark等）の実行完了時間。
2. **メモリフットプリント (RAM)**: 実行時のピークメモリ消費量（スタック、ヒープ、コンテキスト）。
3. **バイナリサイズ (ROM)**: ランタイム自体のコードサイズ。

## ベンチマーク環境
- **ホストOS**: Linux (Ubuntu 22.04 LTS等)
- **アーキテクチャ**: x86_64 (開発効率のため)
- **コンパイラ**: clang-15以上
- **制約条件**:
  - WASMゲストに割り当てるメモリサイズを同一にする。
  - ホストOSのシステムコール（WASI等）は最小限のMockで対応する。

## 実施ステップ
1. **スタンドアロン・ハーネスの構築**: vSoCを単体ライブラリとしてビルドし、WASMバイナリをロードして実行するC++プログラムを作成する。
2. **WAMR環境の構築**: 同一のWASMバイナリをWAMRで実行する環境を構築する。
3. **計測**:
   - 算術演算中心のループ処理。
   - 再帰呼び出し（スタック消費の確認）。
   - メモリアクセス（境界チェックのオーバーヘッド確認）。
4. **分析**: 性能差の要因を特定し、JITテンプレート設計やインタープリタの最適化にフィードバックする。
