# REQ-074 BasicBlock分割位置ベンチマーク

main (`eabbfaa8`) と REQ-074 (`750db32`) をReleaseビルドし、REQ-072と同じ4 workload・CPU固定・perf counter・7プロセス交互計測で比較した。計56プロセスすべてが終了コード0で、期待する出力hashが一致した。

## 条件

CPUはAMD Ryzen 5 5500GT with Radeon Graphics、CPU 2固定、governor powersave、Linux 7.0.0-38-generic、perf 7.0.14、Python 3.13.15。両版のClang Release build flagsは `clang++ -std=c++23 -O3 -flto=thin -fuse-ld=lld -fvisibility=hidden -fno-exceptions -fno-rtti -fomit-frame-pointer -Wall -Wextra -Wpedantic -shared -fPIC -DNDEBUG`。

`perf stat -x, -e instructions:u,cycles:u -- taskset -c 2 <python> <benchmark>`を使用した。呼出しworkloadは10,000 iteration・1プロセス7反復、AO-Bench 32×16はJIT無効・warmup 3回・計測7回・yield threshold 4096。各workload/versionごとに7プロセスを交互順で走らせた。計測前に全workload/versionを1回ずつ起動してbytecode cacheを温めた。
