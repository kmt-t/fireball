AO-Bench Fireball Interpreter / Fireball Hybrid JIT / WAMR Fast 比較
計測日: 2026-10-07

## 目的

同一AO-Bench WASMをFireball NativeInterpreter、Fireball Hybrid JIT、WAMR Fast Interpreterで同一ホスト上で実行した。Interpreterはユーザー指定に合わせ、yieldしきい値を計測プロセス内だけで `0xFFFFFFFF` にした。JITはホットトレースをコンパイルするため、既定しきい値64で実行した。WAMRにFireballのyield機構はない。

## 入力と正当性

- WASM: `experiments/pysim/benchmarks/aobench/aobench.wasm`
- WASM SHA-256: `9f5dc300e96641bf040551f9f56cb6e5bda084e98bde83a3fb1cff9a719d49e9`
- 5解像度×3プロセスで、ウォームアップを含む全出力を3エンジン間でバイト比較した。15組すべて一致した。
- 解像度ごとのフレームSHA-256、全試行サンプル、プロセスごとの中央値、JIT診断カウンターを以下に記録した。
- 1フレームのray数は `width × height + 4 × hit_pixels` とした。

## 実行環境

- CPU: AMD Ryzen 5 5500GT、x86_64、計測プロセスをCPU 2へ固定。
- OS: Ubuntu Linux、kernel `7.0.0-38-generic`。
- Python: CPython `3.13.15`。Clang: Ubuntu clang `21.1.8`。
- Fireball NativeInterpreter / JIT共有ライブラリは現行作業ツリーからClang `-O2`でビルドした。
- WAMR: `third_party/wasm-micro-runtime`、commit `f5f57c09aee623436f5fb87a90798fdd2cdf39fd`、version 2.4.3。Fast InterpreterとWASIを有効にし、AOT/JITを無効にしたClang `-O2 -DNDEBUG`ビルドを使用した。

## 計測方法

各エンジン・解像度につき独立プロセスで3試行を実行した。各プロセスで3フレームをウォームアップし、後続7フレームを計時した。代表値はプロセスごとの7サンプル中央値の中央値である。表の範囲は3プロセス中央値の最小値–最大値である。試行・サイズごとにエンジン実行順を交互にした。

Interpreterの測定ではyieldしきい値を `0xFFFFFFFF` に設定した。JITは既定値64でウォームアップ・測定した。別途、同じJIT設定の診断用RuntimeStatsEngineを3フレーム実行し、JITトレース呼び出し数が0より大きいことを確認した。診断実行は時間計測から除外した。JITの時間にはRuntimeEngine境界と計測区間中に発生するJITランタイム処理を含む。

FireballはWASM解析、System/WASI/Interpreter生成を計測区間から除外し、NativeInterpreterまたはRuntimeEngineのcallを計時した。Fireball標準出力はPython WASI/HALとメモリ内`StreamTransport`を通る。WAMRはruntime初期化、WASMロード、instantiate、exec environment生成を除外し、`wasm_runtime_call_wasm()`を計時した。WAMRのWASI標準出力は一時ファイルへ出力する。これはホスト統合込みの比較であり、opcodeディスパッチや生成コード単体の比較ではない。

再実行時のコマンド:

```bash
taskset -c 2 env UV_CACHE_DIR=/tmp/fireball-uv-cache UV_OFFLINE=true UV_NO_SYNC=true \
  uv run --project . --offline --no-sync python /tmp/fireball_all_engines_aobench.py \
  --wamr-binary /tmp/wamr_aobench_runner_20261007 \
  --raw-dir /tmp/aobench_all_engines_yieldmax_20261007 \
  > /tmp/aobench_all_engines_yieldmax_20261007.log 2>&1
```
